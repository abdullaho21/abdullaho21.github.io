Voice software

Open source

Jarvis

Voice control for the Linux desktop that runs entirely offline, with no cloud service and no API key. Open apps, switch workspaces, change the volume or save a clip by speaking.

  • 1.05 smedian command latency
  • 0.2–0.6%of one core while listening
  • 176automated tests
  • Vosk catches the wake word and Whisper transcribes the command, both on the CPU.
  • Speech maps to an allowlist of actions. It can never run a shell command, and audio is never stored.

Built with: Python · GTK 4 · Whisper · Vosk · PipeWire · Hyprland

Localization · Unity & Unreal

In-game testing

Arabic for games that shipped without it

Homura Hime (Unity 6) and What Remains of Edith Finch (Unreal Engine) have no Arabic. I built the tooling that adds it: text extraction, an Arabic grammar checker, right-to-left rendering, and installers that only add files.

  • 10,954of 10,991 strings translated
  • 8,755dialogue lines
  • 493 / 493RTL layout checks pass
  • A BepInEx plugin hooks Unity’s UI.Text, TextMeshPro and the Utage dialogue engine, so Arabic reads right to left with the game’s own line breaks.
  • A pronoun and gender-agreement checker built on CAMeL Tools reviews every batch before a person does. In Edith Finch, where most words are 3D models, I built 4,691 Arabic glyph models in the game’s own format and played it through in Arabic from start to finish.

Built with: C# · BepInEx · Harmony · Unity · Python · CAMeL Tools · Unreal Engine

Reverse engineering · C++

Private research

Gravity Rush Remastered, read from its own data

Private research into the PS4 release’s undocumented formats. I decoded its world, model, animation and event files, then wrote C++ readers and a renderer that draw the opening area from the original data.

  • 153,904triangles, matched byte for byte
  • 447world meshes drawn
  • 17world models
  • Each decoder is checked against a sealed reference digest, so every result can be reproduced.
  • Ground rules: game data stays read-only, no DRM circumvention, nothing redistributed.

Built with: C++ · Direct3D · MSVC · Wine · Python
